# Sample PDFs

Three short PDFs to try Warqa with, one for each kind of book it makes. They were written for this project
and are shared under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/): use them freely, credit
"Warqa project".

| File | What it is | Good for testing |
|---|---|---|
| [`maths-college-ar.pdf`](maths-college-ar.pdf) | Arabic maths, first year of collège: relative numbers, the number line, adding and subtracting, exercises (5 pages, 2 chapters) | Arabic text, math inside Arabic, number lines, questions |
| [`science-water-cycle-fr.pdf`](science-water-cycle-fr.pdf) | French science (SVT): the water cycle, with a diagram and Moroccan examples (4 pages, 1 chapter) | French, any-document lessons, translation into Arabic |
| [`story-zitoun-ar.pdf`](story-zitoun-ar.pdf) | An Arabic picture book: Zitoun the fox (6 pages) | Children's books, pictures, read-along, Darija |

**How to use one:** in the studio or the web app, create a book, choose the languages (for example Arabic
and French), and drop the PDF. Then read it, make the plan, approve it and build the first chapter. To
download from GitHub, open the file and click *Download raw file*.

The PDFs are generated by `packages/pipeline/test-fixtures/make-samples.mjs`
(`node packages/pipeline/test-fixtures/make-samples.mjs` rebuilds them).
