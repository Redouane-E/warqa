# Getting help

Warqa is made by volunteers. We answer as well and as fast as we can, in **English, Arabic or French**
(يمكنك الكتابة بالعربية · vous pouvez écrire en français).

## I am a teacher or a parent

1. Read the short guide for your language: [English](docs/en/start-here.md) · [العربية](docs/ar/start-here.md) · [Français](docs/fr/start-here.md).
   It covers the three ways to use Warqa, getting an AI key, the cost, and what to do when something goes wrong.
2. Still stuck with a book? Open an issue with the **"My PDF didn't work"** form. No technical knowledge is needed.
3. A question, an idea, or a book you want to show? Post it in **Discussions**.

## I am a developer

- Setup, repository map and how to contribute: [CONTRIBUTING.md](CONTRIBUTING.md).
- Reference: [getting started](docs/en/getting-started.md), [lesson format](docs/en/lesson-format.md),
  [components](docs/en/components.md), [models](docs/en/models.md), [voices](docs/en/voices.md),
  [exports](docs/en/exports.md), [agents (MCP)](docs/en/agents.md).
- `warqa doctor` checks your machine; `WARQA_DEBUG=1` prints stack traces.
- Bugs: the **Bug report** form. Ideas: **Feature request**, **New component** or **New language**.

## Where to ask what

| You want to… | Go to |
| --- | --- |
| ask how to do something | Discussions → Q&A |
| report a problem with a PDF | Issues → "My PDF didn't work" |
| report a bug | Issues → "Bug report" |
| suggest a feature, a component or a language | Issues → the matching form |
| fix a translation of the interface | Issues → "Translation or wording fix", or a pull request |
| report a security problem | **privately**, see [SECURITY.md](SECURITY.md) — never in a public issue |

## Before you post

- **Never paste an API key**, even a revoked one. Remove keys from logs and `.env` excerpts.
- Do not upload PDFs you are not allowed to share, or anything about your students.
- Say which version you use (`pnpm warqa --version`, the release, or "web app") and how you run Warqa.

There is no paid support. If your school or organisation wants to sponsor work on Warqa, open a Discussion.
