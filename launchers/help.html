تشغيل «ورقة»

لم نجد على هذا الحاسوب ما يلزم لتشغيل «ورقة»: يحتاج البرنامج إلى Docker Desktop أو إلى Node.js 22 (أو أحدث). اختر إحدى الطرق الثلاث:

  1. دون أي تثبيت: استعمل نسخة الويب مباشرة في متصفحك.
    افتح نسخة الويب
  2. الطريقة الأسهل للتثبيت: ثبّت Docker Desktop، ثم شغّله وانتظر حتى يصبح جاهزًا، ثم انقر نقرًا مزدوجًا على ملف التشغيل من جديد.
  3. أو: ثبّت Node.js (الإصدار 22 LTS أو أحدث)، ثم انقر نقرًا مزدوجًا على ملف التشغيل من جديد.

التشغيل الأول قد يستغرق بضع دقائق. للمزيد: دليل البداية.

Démarrer Warqa

Il manque sur cet ordinateur ce qu’il faut pour lancer Warqa : Docker Desktop ou Node.js 22 (ou plus récent). Choisissez l’une de ces trois solutions :

  1. Sans rien installer : utilisez la version web, directement dans votre navigateur.
    Ouvrir la version web
  2. L’installation la plus simple : installez Docker Desktop, lancez-le, attendez qu’il soit prêt, puis double-cliquez à nouveau sur le lanceur.
  3. Ou bien : installez Node.js (version 22 LTS ou plus récente), puis double-cliquez à nouveau sur le lanceur.

Le premier démarrage peut prendre quelques minutes. Pour en savoir plus : le guide de démarrage.

Starting Warqa

This computer is missing what Warqa needs to run: Docker Desktop or Node.js 22 (or newer). Pick one of these three ways:

  1. Nothing to install: use the web version, right in your browser.
    Open the web version
  2. Easiest install: install Docker Desktop, start it, wait until it is ready, then double-click the launcher again.
  3. Or: install Node.js (version 22 LTS or newer), then double-click the launcher again.

The first start can take a few minutes. More help: the start-here guide.
