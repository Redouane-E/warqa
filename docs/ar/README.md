# ورقة — Warqa

**حوّل ملف PDF إلى كتاب تفاعلي متحرك ومسموع، بالعربية والدارجة والفرنسية والإنجليزية، وبأي نموذج ذكاء اصطناعي تختاره.**

**للأساتذة والآباء:** لا حاجة إلى البرمجة. ابدأ من [دليل البداية](start-here.md)، أو جرّب [التطبيق في المتصفح](https://redouane-e.github.io/warqa/) دون أي تثبيت.

يقرأ «ورقة» الكتاب، ويخطط لسلسلة دروس قصيرة، ويكتب كل درس على شكل **مقاطع**: سرد صوتي تتزامن معه تغييرات بصرية تحدث عند الكلمات التي تشرحها بالضبط، مع أسئلة تحقّق وتمارين **داخل الصورة نفسها**. يمكنك المشاهدة والاستماع والإيقاف والإجابة وتغيير اللغة في منتصف الدرس. والنتيجة موقع ثابت يعمل دون اتصال بالإنترنت، دون خادم ولا حساب.

## لماذا «ورقة»؟

- **أي نموذج:** Claude وGPT وGemini وMistral وDeepSeek وGrok، وكل نماذج OpenRouter، أو **محليًا بالكامل** عبر Ollama أو LM Studio أو llama.cpp أو vLLM. يمكنك اختيار نموذج لكل دور (التخطيط، الكتابة، الترجمة، قراءة الصفحات…). النماذج لا تكتب شيفرة ولا إحداثيات: تملأ صيغة درس مضبوطة، وتُعاد إليها الأخطاء لتصحّحها، والنماذج الصغيرة تحصل على صيغة أبسط تُوضَع فيها الحركات تلقائيًا.
- **العربية أولًا:** اتجاه من اليمين إلى اليسار يعكس ما يجب عكسه (ترتيب القراءة، الخط الزمني، البطاقات، التنقل) ويحافظ على ما لا يُعكس (المستقيم المدرج، المعلم، الرياضيات). تُكتب الرياضيات بالترميز اللاتيني من اليسار إلى اليمين داخل النص العربي كما في الكتب المدرسية المغربية. تُقبل الأرقام الهندية (٠–٩) والفاصلة العشرية في الإجابات. يُكتشف نص PDF العربي المشوّه (أشكال العرض، الأسطر المعكوسة) ويُصلَح أو يُرسَل إلى التعرف الضوئي على الحروف. أصوات عربية مع توقيت الكلمات، منها الأصوات المغربية (ar-MA).
- **ترجمة من أي لغة إلى أي لغة:** لكل درس بنية واحدة مستقلة عن اللغة وجدول نصوص لكل لغة، والترجمة تحافظ على كل علامة توقيت وخانة إجابة ومعادلة.
- **تعليم لا عرض شرائح:** المشهد يستمر بين المقاطع، والمكوّنات حيّة (معادلة تتحوّل خطوة بخطوة، قفزات على المستقيم المدرج، ميزان يميل)، وقواعد التحقق تفرض الإيقاع.
- **مفتوح المصدر ومحمول:** رخصة Apache-2.0. الكتب مجلدات JSON يمكن تعديلها. التصدير: موقع ثابت، ملف zip، حزمة **SCORM** لمنصات مثل Moodle، بطاقات **Anki**، CSV، وفيديو **MP4**.

## الجديد

- **الدارجة المغربية** لغةً كاملة للكتب (`ary`): يكتب النموذج بالدارجة كما يشرح الأستاذ في القسم، بالحرف العربي، وتظهر واجهة المشغّل بالدارجة.
- **القراءة المصاحبة:** تُضاء الكلمة التي تُقرأ في القصص المصوّرة وفي الترجمة النصية.
- **الخرائط:** الدول، و**جهات أي بلد** (مثل الجهات الاثنتي عشرة للمغرب عبر `warqa geo add MAR`)، مع أسئلة «انقر على الجهة».
- **الرياضيات:** كتابة أي معادلة بصيغة TeX (كسور متداخلة، جذور، مصفوفات، كيمياء، حلّ خطوة بخطوة) تُنضَّد بـ MathJax.
- **ذاكرة الترجمة ومراجعتها:** صياغة واحدة للجملة نفسها في كل الفصول، وتحقّق من المصطلحات، ومراجعة الأستاذ في الاستوديو أو في جدول (Excel)، والصياغة التي يعتمدها الأستاذ لا يغيّرها النموذج أبدًا.
- **الجودة:** نموذج رؤية يقيّم صورة كل مقطع وتُعاد كتابة المقاطع الضعيفة تلقائيًا (`warqa improve`)، و**لجان تقييم من الأساتذة** بتقييم أعمى تُنشر نتائجها مع ترتيب النماذج.
- **حزم مكوّنات** يكتبها أي أحد (مثل ساعة لتعلّم قراءة الوقت).
- **تطبيق في المتصفح** دون تثبيت (المفاتيح تبقى في متصفحك)، و**مشغّلات بنقرة واحدة** لويندوز وماك ولينكس.

## جرّبه

```bash
git clone https://github.com/Redouane-E/warqa && cd warqa
pnpm install && pnpm build
pnpm warqa preview examples/integers.warqa
```

ثم افتح ‎http://127.0.0.1:8765/‎ — درس عن طرح الأعداد الصحيحة النسبية بالعربية والفرنسية والإنجليزية.

## اصنع كتابك

```bash
pnpm warqa init my-book --pdf textbook.pdf --langs ar,fr --default ar --audience "السنة الأولى إعدادي"
cd my-book
warqa ingest            # قراءة الملف: النص، إصلاح العربية، التعرف الضوئي، الفصول
warqa plan              # مسودة خطة الكتاب ← راجع plan.json
warqa plan --approve
warqa build --chapter ch01
warqa preview
```

أو استعمل **الاستوديو** في المتصفح: `pnpm studio` (الكتب في مجلد `books`) أو `pnpm warqa studio examples` لفتح المثال، أو `docker compose up` — ارفع الملف، اختر النماذج، راجع الخطة، اصنع الفصول، عدّل المقاطع مع معاينة مباشرة، ترجم، أضف الصوت، وصدّر.

## النماذج

`warqa models status` يعرض المزوّدين الذين لديك مفاتيحهم والإعدادات الجاهزة المتاحة (`best`، `google`، `budget`، `openrouter`، `local`…). للعمل محليًا دون إرسال أي بيانات:

```bash
ollama pull qwen3:14b qwen2.5vl:7b
warqa models set preset=local
```

## الترخيص والشكر

مرخّص بموجب Apache-2.0. يعتمد على أفكار وشيفرة من مشروع [Papermorph](https://github.com/DozenTwelve/Papermorph) (رخصة MIT). الكتب التي تصنعها ملك لك؛ احترم حقوق ملفات PDF التي تستعملها.
